# Consumer Insights & Marketing Analytics  
## Customer Segmentation, Brand Performance, and Commercial Strategy (R Project)

---

## Project Overview  
This project applies consulting-style marketing analytics and consumer insights methodologies using **R** to segment customers based on purchasing behavior and commercial value.

Using **RFM (Recency, Frequency, Monetary) Analysis**, **K-Means Clustering**, and statistical consumer behavior analysis, this project transforms raw retail transaction data into actionable customer segments for strategic marketing, retention, and promotion optimization.

---

## Business Problem  
Organizations often possess large-scale transactional datasets but lack structured frameworks to:

- Identify high-value customers  
- Detect churn-risk segments  
- Personalize promotions  
- Improve customer retention  
- Allocate marketing resources effectively  
- Enhance commercial performance  

### Objective:
To build a consumer insights and segmentation framework that supports:

- Customer retention strategy  
- Promotion optimization  
- Brand performance understanding  
- Commercial decision-making  
- Consumer insights development

## Segment Profiles  

### High Value Customers:
- Recent activity  
- High frequency  
- High spending  

### Loyal Customers:
- Consistent purchase patterns  
- Stable long-term value  

### At-Risk Customers:
- Previously valuable but declining engagement  

### Lost Customers:
- Low activity and low recency

## Key Strategic Insights

- High-value customers contributed disproportionate revenue concentration  
- At-risk segments represented significant retention opportunities  
- Segment-specific targeting improved promotion efficiency  
- Behavioral segmentation enhanced strategic marketing precision
